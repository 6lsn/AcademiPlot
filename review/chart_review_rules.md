# 科研绘图 AI 审图规则

本模块用于判断生成图是否适合作为数学建模/统计建模论文图。审图不只看美观，还要结合建模主题、图表类型、变量含义、图注和 annotation 判断图是否服务论文论证。

## 不同建模问题适合哪些图

| 建模问题 | 优先图型 | 慎用图型 |
|---|---|---|
| 评价类 | 柱状图、分组柱状图、堆叠柱状图、箱线图、热力图、雷达图少量使用 | 饼图、3D 图、过密雷达图 |
| 预测类 | 时间序列图、折线图、带趋势线散点图、置信区间图、残差图 | 饼图、普通堆叠图、没有时间轴的 3D 图 |
| 优化类 | 帕累托图、瀑布图、等高线图、敏感性分析图、方案对比图 | 只有装饰效果的 3D 曲面 |
| 聚类分类类 | 分组散点图、聚类树状图、混淆矩阵、降维散点图 | 饼图、过多类别雷达图 |
| 物理工程空间类 | 矢量场、等高线图、空间热力图、必要时使用 3D 曲面 | 难以读数的 3D 散点 |
| 统计处理类 | 直方图、KDE、箱线图、相关热图、散点矩阵 | 高密度散点矩阵正文图 |

## 哪些图适合正文

正文图应直接服务主要结论，优先选择读者能快速比较、定位趋势或验证模型假设的图：

- 主要趋势、模型结果、方案对比和关键敏感性分析。
- 坐标轴、图例、变量含义完整，图注能概括核心信息。
- annotation 克制，正文图最多 3 个，建议 0-2 个。
- 若 metadata 指定 `recipe`，审图需检查该表达范式是否匹配论文目的：达标/阈值优先 bullet，双方案差异优先 dumbbell，参数寻优优先 contour，供需平衡优先 balance 复合图。

## 哪些图适合附录

附录图适合承载探索性、诊断性或高信息密度内容：

- 散点矩阵、完整相关热图、大量类别箱线图。
- 多参数搜索过程、模型诊断残差、完整聚类树。
- 不直接支撑主结论但有助于复核过程的图。

## annotation 使用边界

annotation 是解释性增强，不是装饰，也不是正式图注。只用于突出关键变化、事件节点、阈值线、极值点和阶段变化。

- 模板默认 `annotate=False`，不得自动写入图中。
- 模板可以根据数据返回 `suggested_annotations`，但不得直接写入图中。
- 只有用户显式设置 `annotate=True`，并提供 `annotation_config` 时，才写入标注。
- `auto_annotation=True` 只能触发建议生成与规则校验，不能绕过显式写入条件。
- paper 最多 3 个 annotation，presentation 最多 4 个，appendix 最多 1 个。
- annotation 不得重复图例、坐标轴或数据标签已经表达的信息，不得逐点解释，不得写缺乏证据支撑的因果性解释。

## 图注与图内标题边界

图注应在 Word 或论文正文中承担正式说明。图内标题只允许作为简短业务主题，不应写“图 1”“柱状图”“模型结果展示”等正式图注或图表类型名。

审图时若发现图内大标题占用过多空间、图题与图注重复、caption 不能概括图中变量和结论，应建议修订。

## 布局自动质检边界

`scripts/layout_qa.py` 只检测可几何判定的硬伤：图例或普通说明文字明显超出 figure 边界。它默认跳过轴刻度文字，避免把轻微 tick label 外溢误判为版式失败。

layout QA 通过不代表图已经美观；仍需人工检查遮挡、图例压字、空白过大、颜色语义冲突和论文版心中的实际裁切效果。

## 自动返工边界

`chart_auto_reviser.py` 只执行不会改变建模含义的低风险返工：

- 缺失图注：用审图建议图注补齐 metadata。
- 坐标轴/变量字段缺失：在已有变量或轴标签之间互相补全。
- annotation 超出数量上限：按 paper/presentation/appendix 限额裁剪。
- 慎用图型启用 annotation：自动关闭 annotation，避免在 3D、热力图、雷达图、散点矩阵等高密度图中堆叠说明框。

自动返工不得修改原始数据、变量含义、问题类型或图型选择；不得自动删除疑似因果解释来伪装合规。涉及这些问题时应保留审图意见并进入人工复核或重画流程。

## 3D 图、饼图、雷达图、散点矩阵的慎用规则

- 3D 图：仅在空间结构、响应曲面或物理工程问题中使用；正文优先给 2D 等高线或投影版本。
- 饼图：仅适合少类别构成比例展示；定量比较应优先条形图。
- 雷达图：适合少量方案和少量指标的展示型比较；正文中若指标多或方案多，应改为表格或柱状图。
- 散点矩阵：适合附录探索，不适合正文主图；正文应选择关键变量散点图或相关热图。
- 热力图：适合矩阵关系或相关性展示，但 annotation 应非常克制。
